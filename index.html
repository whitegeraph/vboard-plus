We are trying to solve a problem

A virtual keyboard with all the keys you need. On Wayland.

The gap

Even moderately basic desktop use needs keys like Ctrl, Alt, Tab, Super, F1–F12, and the arrow keys, especially for terminals, shortcuts, and window navigation. The on-screen-keyboards shipped by KDE Plasma and GNOME do not include that full set.

Onboard supports this style of fuller keyboard layout, but it does not work on Wayland.

The answer

vboard-plus (a fork of vboard) provides a lightweight, resizable keyboard with a toggleable F1–F12 function row, Arabic layout, automatic system layout synchronization, optional word suggestions, tray support, and a uinput-based input backend built for modern GNU/Linux desktops.

Ideal for

Touchscreen devices, kiosks, accessibility workflows, and systems whose physical keyboards are missing, damaged, or simply inconvenient.

Install

Fast paths for Ubuntu, Arch, and everything else.

Ubuntu

Package or source

On Debian and Ubuntu based systems, you can install the .deb installer from vboard-plus GitHub Releases, or build directly from source. (The upstream vboard project is also available in the upstream vboard PPA.)

Install from GitHub release

Download the latest .deb from GitHub Releases, then install it with: 

sudo apt install ./vboard-plus_*.deb

Do not use dpkg alone if dependencies are missing. Use apt.

Reboot or log out and back in after installation for uinput permissions to apply cleanly.

Build and install with Meson

git clone https://github.com/whitegeraph/vboard-plus.git
cd vboard-plus
sudo bash scripts/setup-uinput.sh
meson setup builddir --prefix=/usr/local
meson compile -C builddir
sudo meson install -C builddir

Reboot after installation for the uinput permissions to apply cleanly.

Automated Ubuntu/Debian setup

git clone https://github.com/whitegeraph/vboard-plus.git
cd vboard-plus
sudo bash setup-ubuntu-debian.sh

Reboot after installation for the uinput permissions to apply cleanly.

Arch

Build from PKGBUILD or Meson

Build the vboard-plus package locally using the included AUR/PKGBUILD or install directly with Meson.

Build and install locally

git clone https://github.com/whitegeraph/vboard-plus.git
cd vboard-plus/AUR
makepkg -si

Reboot after installation so the desktop session picks up the new device permissions cleanly.

History

Vboard was initially developed by mdev588. After that project was abandoned, development and maintenance were continued in the upstream vboard repository. vboard-plus is a fork of that upstream project adding responsive resizing, a toggleable F1–F12 function row, Arabic layout, and automatic system layout sync.

To report issues or suggest new features, visit the vboard-plus issue tracker.
